# EasySales — сайт-визитка

Простой статический одностраничный сайт для **EasySales** (CRM для малого бизнеса) на чистом HTML/CSS/JS, с переключателем языков (RU / ET / EN) и встроенной **Политикой конфиденциальности**.

Готов к публикации на **GitHub Pages** без сборки.

## Структура

```
index.html          — главная страница
css/styles.css      — стили (адаптивные, тёмный футер, градиентный бренд)
js/i18n.js          — словари для RU / ET / EN
js/app.js           — переключение языка, мобильное меню, форма
assets/favicon.svg  — иконка
.nojekyll           — отключает Jekyll на GitHub Pages
```

## Локальный просмотр

Любым статическим сервером, например:

```bash
python3 -m http.server 8080
```

Затем открыть http://localhost:8080/

## Публикация на GitHub Pages

1. Запушьте этот репозиторий на GitHub.
2. Откройте **Settings → Pages** в репозитории.
3. В **Source** выберите ветку (например `main`) и папку `/ (root)`, нажмите Save.
4. Через минуту сайт будет доступен по адресу:
   `https://sharpgraf.github.io/easysales-website/`

Никакого билда не требуется — GitHub Pages раздаёт статику как есть.

## Как редактировать контент

- Тексты правите в `js/i18n.js` (по три версии на каждый ключ: ru / et / en).
- Контакты, email и телефон — в `index.html` в секции `#contact` и в Политике (`#privacy`).
- Цветовую схему меняйте через CSS-переменные в самом верху `css/styles.css` (`--brand`, `--brand-2`).

## Переключатель языков

По умолчанию — русский. Язык сохраняется в `localStorage` и подхватывается при повторном заходе.
